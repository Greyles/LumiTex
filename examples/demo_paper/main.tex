\begin{abstract}
This is a simple English LaTeX template for daily testing and course writing. It contains basic sections, formulas, tables and figures, with simple code structure and no redundant packages. The whole document is about two pages and can be compiled normally without errors.
\end{abstract}

\section{Introduction}
LaTeX is widely used in academic writing for its neat layout and stable formula display. For beginners, a simple and clean template is more suitable for daily study and simple paper writing. This document provides a lightweight version to avoid complex configuration and compilation errors.

In general academic tasks, basic text, mathematical formulas, data tables and simple pictures are enough to complete most writing requirements. This template fully meets these basic needs.

\section{Discussion}
Simple writing can effectively reduce format errors and improve writing efficiency. Too many advanced packages will increase the probability of compilation errors. Therefore, lightweight templates are more friendly for beginners and simple testing tasks.
